# Consent Location Demo

## التشغيل محليًا
1. ثبّت Node.js.
2. افتح المجلد في الطرفية.
3. شغّل: `npm install`
4. شغّل: `ADMIN_TOKEN=ضع_رمزًا_قويًا npm start`
5. افتح `/` للمستخدم و`/admin.html` للوحة الإدارة.

## النشر
انشر المشروع على خدمة تدعم Node.js مثل Render أو Railway، واضبط متغير البيئة `ADMIN_TOKEN` على رمز قوي.

ملاحظة: تحديد الموقع في المتصفح يحتاج HTTPS عند الاستخدام خارج localhost. يجب إبلاغ المستخدم بوضوح أن موافقته ستشارك موقعه مع صاحب الخدمة.
